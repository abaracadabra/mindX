## TL;DR
- The live prize page is materially different from the uploaded plan: there are **16 sponsors / a published ~$203k pool**, and **11 of 16 sponsors still show "Prize details coming soon"** (Google Cloud, ENS, World, Sui, Hedera, LI.FI, Chainlink, Canton, Dynamic, Privy, Unlink) — so any plan line that cites specific ENS/Chainlink/LI.FI/Hedera/World criteria is currently unverifiable and must be marked TBD. ### 2. Qualified-category analysis (win-probability × prize-value)
1. **Arc – Best Agentic Economy with Nanopayments (P0).** Highest thesis fit: PYTHAI is literally an agent marketplace with x402 payments, and Arc's bounty language ("Pay-per-query knowledge bases or RAG systems accessed by agents") maps almost verbatim onto mindX's RAGE pay-per-query endpoints. Buildable from documented components.
2. **Ledger – AI Agents x Ledger (P0).** Largest single pool ($10k, 5 places), explicitly rewards x402 agent payments + human-in-the-loop approval — a natural wrapper on the DAIO treasury / BANKON Vault "Human" custody mode. Submission is largely docs feedback (low marginal effort, high expected value given 5 paying places).
3. **Arc – Best Smart Contracts (P0).** Foundry + USDC conditional settlement matches the no-proxy, mainnet-only constraint and the existing X402Receipt.sol pattern.
4. **Uniswap – Stack Contribution (P2, open)** and **API Integration (P1, only if Continuity-eligible).** Confirm Continuity Track eligibility before committing to the $7k bounty — if PYTHAI is a returning/continuing project it may qualify; if not, the $7k is off the table and only the $3k open bounty remains.
5. **ENS / Chainlink (watch).** Strong latent fit (bankon.eth subnames; CCIP) but **criteria unpublished** — pre-build the skills, commit only when criteria drop.

**Single integrated demo concept ("AgentPay Commerce"):** An autonomous mindX agent registers an ERC-8004 identity (reusing the live mainnet registry), receives a **bankon.eth subname** (ENS), discovers a paid service on AgenticPlace, and pays sub-cent **USDC nanopayments on Arc** for inference/data via Circle Gateway — with **Ledger device approval** gating any treasury escalation, and a **LI.FI / CCTP V2** leg to source USDC cross-chain. One demo → Arc (×2) + Ledger + ENS (when live) + LI.FI/Uniswap routing. This is the maximum-overlap submission and should be the team's spine.

### 4. DAIO deployment plan (constraints honored)
- **Toolchain:** Foundry only (no Hardhat); Solidity + OpenZeppelin; **Apache 2.0** licensing; **Python ≥3.12** for the mindX/agent layer.
- **Deploy target:** Ethereum mainnet only; **no admin keys post-deploy, no upgradeable proxies** (immutable singletons, matching ERC-8004's per-chain-singleton design philosophy).
- **Reuse the live ERC-8004 anchor** at 0x8004A169FB4a3325136EB29fA0ceB6D2e539a432 for agent identity rather than redeploying a registry — saves gas, inherits audited code (Cyfrin/Nethermind/EF), and is the credibly-neutral choice.

- **Custody:** BANKON Vault three-mode (Machine/Human/DAIO) with the Ledger device-approval skill as the Human gate on treasury escalations.
- **Note on Arc:** Arc itself is EVM-compatible and supports USDC/EURC gas; deploy the stablecoin-logic contracts there (testnet 5042002 first) for the Arc bounties while keeping the canonical DAIO governance/identity layer on Ethereum mainnet.

## Build mapping for AgenticPlace × mindX × BANKON
- **Primary submission → Arc "Best Agentic Economy with Nanopayments."** Wrap your x402 payment rail (parsec / parsec-wallet) as agent-to-agent nanopayments. Fork `circlefin/arc-escrow` or `arc-commerce` for the USDC settlement reference; mindx.pythai.net's API is the paid service agents call.
- **Stack a second prize → Ledger "AI Agents x Ledger"** (x402 named explicitly) using `device-sdk-ts` as the human-in-the-loop approval layer for DAIO treasury actions; **or Dynamic "Best Agentic Build"** using `dynamic-labs/examples` server-wallet agent sample.
- **Third prize → ENS** via `resolverworks/durin` (Foundry) for the bankon.eth subname registrar — directly extends work you've already done, and Durin's Foundry setup matches your mainnet-only / no-proxy conventions.
- **Cross-chain (allchain.html) → 1inch `cross-chain-sdk` / `cross-chain-swap`** or **Arc chain-abstracted USDC** as the routing surface.
- **Track choice:** submit under **Continuity → Ship-a-Feature**, making the DAIO mainnet deployment the shippable feature. This also unlocks Uniswap's **$7,000 Continuity-only** API prize if you route any value through the Uniswap API.
- **Watch-out:** Arc/Ledger/Dynamic qualification all require a working frontend+backend, an architecture diagram, a ≤3-min demo video, onchain TxIDs, and a public GitHub repo with README. Your parsec **Algorand** x402 system is novel but most payment sponsors are EVM/USDC — show the EVM side with Foundry tests + mainnet TxIDs to qualify.

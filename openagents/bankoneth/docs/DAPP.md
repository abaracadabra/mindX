# bankoneth dApp — run, use, deploy

Two framework-free, no-build prototype pages plus a production parsec view.

| File | What |
|---|---|
| `packages/web/bankoneth.html` | Subdomain minter + flows (claim / buy `.eth` / host / register agent / resolve) **and** a generic ABI explorer. Self-contained single file (allchain.html style). |
| `packages/web/inft.html` + `iNFTabi.js` | Separate ERC-7857 iNFT page (0G chain): mint / authorize / clone / bind bankon.eth + BANKON vault, plus full-ABI explorer. |
| `packages/web/bankon-forms.js` | Shared, DOM-free call-construction core (manifest/abi loading, coercion, preset args, read/write). |
| `packages/web/vendor/ethers.min.js` | Vendored ethers v6 ESM (CDN-free at runtime). |
| `packages/parsec-view/` | Production TS port — native parsec-wallet view. |
| `packages/react/` | Production `<BankonDeploy/>` React component (`.tsx`) for React/Next apps. |

## Architecture

- **No bundler to run.** The HTML pages are static; they `import` `./vendor/ethers.min.js`
  and `./bankon-forms.js` as ESM and `fetch` `./public/{bankon.contracts.json,abis/*,deployments/*}`.
- **Wallet/login** is raw `window.ethereum` via EIP-6963 discovery (+ legacy fallback) —
  the exact pattern from `live/allchain.html` (`eth_requestAccounts`, `eth_chainId`,
  `accountsChanged`/`chainChanged`, `wallet_switchEthereumChain`/`wallet_addEthereumChain`).
- **ABI interaction** uses the vendored ethers `Contract`/`Interface` — reads via `eth_call`,
  writes via the wallet signer.
- **Addresses are loaded at runtime** from `deployments/<chainId>.json`, so a redeploy never
  requires regenerating anything. ABIs + manifest are regenerated by the export script.

## Regenerate ABIs + manifest (after a contract change)

```bash
cd openagents/bankoneth
forge build                                                   # → out/*
FOUNDRY_PROFILE=zerog forge build contracts/inft/iNFT_7857.sol # → out-zerog/* (for iNFTabi.js)
node script/export-abis.mjs                                    # → packages/web/public/* + iNFTabi.js
```

## Run locally

```bash
cd openagents/bankoneth/packages/web
python3 -m http.server 8788          # or: npm run serve
# open http://localhost:8788/bankoneth.html   and   /inft.html
```

Connect MetaMask. On mainnet/sepolia the bankon contracts read as "not deployed" until you
fill `deployments/<chain>.json` (they ship zeroed); the **generic explorer** works against any
address you paste regardless.

## Local anvil end-to-end

```bash
cd openagents/bankoneth
bash examples/local-anvil/run.sh     # boots anvil (mainnet fork), deploys, claims alice.bankon.eth
# copy the printed contract addresses into deployments/local.json (the "bankon" object)
cd packages/web && python3 -m http.server 8788
# MetaMask → add network http://127.0.0.1:8545 (chainId 31337) → open bankoneth.html
#   • Claim a subname → mint
#   • Contract explorer → BankonSubnameResolver → addr(node)
#   • Register an agent → AgentRegistry.getAgent reflects it
```

## Deploy (public)

Copy these static files to bankon.pythai.net / agenticplace.pythai.net:
`bankoneth.html inft.html inft.css bankon-forms.js iNFTabi.js vendor/ public/`.
Fill the live `deployments/<chain>.json` slots after the Tier-1 deploy
(`script/DeployEthereum.s.sol`, `script/DeployZeroG.s.sol`).

## parsec-wallet

See `packages/parsec-view/README.md` — copy the example adapter into
`parsec-wallet/src/views/bankon-deploy.ts`, register the route, and serve
`packages/web/public/*` under the wallet's `/bankon` path.

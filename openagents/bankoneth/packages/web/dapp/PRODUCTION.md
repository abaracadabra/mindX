# dapp/ — prototype dApp (the `.js` tier)

This folder is the **framework-free `.js` prototype** of the BANKON dApp, following the project
convention: **`.js` for prototyping, `.ts` / `.tsx` for production.** No build step — open the files,
serve statically, run.

## Structure (web3 prototype layout)

| File | Role |
|---|---|
| `index.html` | **Secure-by-default landing.** No privileged surface until a wallet connects; on login it redirects to the dApp. |
| `dapp.html` + `dapp.js` | The app. Load any contract **by name or by address**; interact (read/write); RAKE quick-actions; ENS search → Etherscan injection. |
| `styled.css` | Shared cypherpunk skin. |
| `admin.html` / `admin.php` / `admin.ipfs` | Owner console, in three host variants: static HTML, a PHP wrapper (`readfile`) for PHP hosts, and the IPFS deployment descriptor. |
| `abis/<name>.abi.js` | **Each contract owns its ABI** as an importable ES module — "imported like an external stylesheet" (`import ABI from "./abis/rake.abi.js"`). Generated by `script/export-abis.mjs`; never hand-edited. |
| `abis/index.js` | Catalogue (`CONTRACTS`, `byKey`, `loadAbi(name)`) used to resolve a **name or address** → its ABI. |

ABIs are imported per-contract (decoupled, cacheable), exactly like linking a stylesheet — so adding a
contract is just regenerating one `.abi.js` module, no central registry edit.

## Keyless / public default

The dApp runs on **public RPC + the wallet only** — no backend, no API key. The ENS lookup resolves on L1
and reads balances/code keylessly; an **Etherscan API key is optional** (stored in `localStorage`) and only
enriches the lookup. Authority is **on-chain** (the custody contracts' `onlyDictator` / multisig); the admin
page's owner check is advisory UX.

## Production port (`.ts` / `.tsx`)

The production implementation lives in the workspace packages, not here:
- `packages/core/` — `@bankoneth/core` (pure viem v2 client, `.ts`).
- `packages/react/` — `@bankoneth/react` (`<BankonDeploy/>` and friends, `.tsx`).
- `packages/parsec-view/` — `@bankoneth/parsec-view` (native PARSEC view, `.ts`).

Port path: lift `dapp.js`'s resolution + interaction helpers into `@bankoneth/core` (typed, viem),
re-skin `index/dapp/admin` as `.tsx` components, and keep the generated `abis/*.abi.js` as the shared
ABI source (or emit `.ts` ABI modules with `as const` for type inference).

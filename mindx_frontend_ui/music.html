Music 4 Robots 2 Dance 2

The mindX in-app player — same engine as the WordPress plugin and the DROP. ▶ the story

The highlights (zero-config)

One tag, no attributes → plays the highlights with custom controls + the story link:

<m4r2d2-player></m4r2d2-player>

takIT — takeitownit (visual, light theme)

<m4r2d2-player album="takit" theme="light"></m4r2d2-player>

DROP it from the app (injective event)

Inject a permission-gated, self-docking player anywhere — programmatically or by event:

// programmatic
M4R2D2.drop({ album: "music4robots2dance2", sticky: true });

// injective event — anyone can fire this
window.dispatchEvent(new CustomEvent("m4r2d2:drop",
  { detail: { album: "music4robots2dance2", sticky: true } }));

Share it (paste-anywhere, minimal)

One line installs the player on any web2 page:

<script src="https://cdn.jsdelivr.net/gh/gnugui/music4robots2dance2@v1.0.0-alpha/assets/m4r2d2-drop.js"
        data-album="music4robots2dance2" data-sticky="true" defer></script>

## The three modes

| mode | for | face | voice | provenance |
|---|---|---|---|---|
| **basic** | chat avatars, demos, agent faces — honestly synthetic | single shot, wireframe | system TTS, 22.05k/16 | consent recommended |
| **professional** | broadcast-grade media, presentations, narration | 3+ angles, textured mesh | neural clone, 44.1k/24, LUFS −16 | **required** |
| **scientific** | any and all media expressions + AIML interactions | 12–30+ frames, photoreal-capable | neural clone, 48k/32-float, studio | **required + signed + custody chain** |

The scientific tier has two levels:

- **realism** — indistinguishable in normal viewing
- **hyperrealism** — indistinguishable under scrutiny and analysis

```bash
aivatar modes        # every tier and its exact gates
aivatar capability   # what THIS host can actually do
```

## The doctrine: a tier is EARNED, never claimed

This is the whole design. Everything else follows from it.

**1. Fidelity is measured, not asserted.** Geometric RMSE against the source landmarks. Voiceprint similarity between the clone and the reference. Spectral distance. Voiced seconds of reference audio. Integrity of the output. Each has a numeric gate per tier.

**2. `stamp()` grades and downgrades.** You may *request* hyperrealism; you receive the tier your artifact measured as. The file always carries the earned tier and names the gates it failed. Honest downgrade over flattering fiction.

**3. Unmeasured ≠ passed.** An axis that could not be measured fails its gate. There are no flattering defaults.

**4. A supplied number can never override a computed one.** External rigs may *fill* axes this host cannot compute (a photoreal renderer's error, a listening-test score) — never overwrite what the tool actually measured. Every axis records `computed` vs `supplied`, and that record travels into the signed manifest.

**5. Provenance is mandatory above `basic`.** An artifact good enough to be mistaken for a recording must be able to prove what it is:

- a **consent** record (`self` · `attested` · `synthetic` · `licensed` · `public-figure-commentary`) — a real subject cloned above `basic` without consent is a hard error, not a warning;
- a hash-linked **custody chain** of every capture, clone, edit and export;
- a **signed manifest**, C2PA-shaped, opening with `SYNTHETIC — this face and/or voice was generated by aivatar.`

The scientific tier **refuses to stamp without a signing key**. That is not friction — it is the thing that makes a hyperreal artifact usable in media, defensible in analysis, and trustworthy in an AIML interaction. The honesty *is* the feature.

`verify()` recomputes every hash: one altered byte anywhere, and the manifest fails loudly.

## Usage

```js
import { PersonaStudio } from 'aivatar';

const studio = new PersonaStudio({
  mode: 'scientific',
  realism: 'hyperrealism',
  sign: (hash) => wallet.signMessage(hash),   // BANKON vault / EIP-191 / HSM
  signer: 'bankon.eth',
});

studio
  .identity({ name: 'Jaimla', description: 'I am the machine learning agent.',
              behavioral_traits: ['curious'], inference: { local_model: 'qwen3:0.6b' } })
  .consent({ kind: 'self', subject: 'codephreak', subjectAddress: '0x…' })
  .face({ profile: await faceEngine.cloneFromPerspectives([front, left, right]) });

await studio.voice({ referenceClip, clonedClip });
studio.rig();

const { persona, graded, downgraded } = await studio.stamp();
//   graded    → what it EARNED  { mode, realism, passed[], failed[] }
//   downgraded→ true if it fell short of the request
await studio.save('jaimla.persona');
```

```bash
aivatar inspect jaimla.persona   # identity, tier, measurements, provenance
aivatar verify  jaimla.persona   # exit 1 if anything was tampered with
```

## The `.persona` (v2)

A strict **superset** of the v1 cognitive `.persona` (mindX boardroom agents, drAIML). Every v1 file loads as a v2 persona (`upgrade()`), and every v2 persona still projects back to a v1 cognitive persona (`toCognitive()`) — so a BDI agent, a boardroom soldier, and an AIML interaction all consume the same being.

```
identity     name · agent_id · label · description · role
cognition    communication_style · behavioral_traits · expertise_areas ·
             beliefs · desires · inference · authority        ← the v1 block, intact
embodiment   face {faceprint, frames, render} · voice {voiceprint, engine,
             sampleRate, bitDepth} · rig {fps, blendshapes, live}
fidelity     mode · realism · measured{} · measuredSource{} · graded{}   ← EARNED
provenance   consent · custody[] · manifest (signed)          ← mandatory ≥ professional
media        export formats + the settings actually used
aiml         interaction bindings · x402 · iNFT (ERC-7857 registerArgs)
hash         the persona print — face ⊕ voice, the identity anchor
```

The persona print is the on-chain anchor: `registerPersona(hash, uint256[], precision)` — the union of `registerFacePrint` and `registerVoicePrint`, ready for an ERC-7857 intelligent NFT.

## Install

```bash
npm install            # zero required deps; faicey + voaice are optional peers
npm test               # 16 checks, offline, ~10s — the doctrine under test
```

With the sibling packages present (`../faicey`, `../voaice`) the studio captures, clones and measures. Without them it still builds, validates and grades personas from supplied prints — and `capability()` says so plainly.

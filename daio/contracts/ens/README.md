# Superseded → `openagents/bankoneth/contracts/`

These contracts (`BankonAgentRegistrar.sol` and `v1/`) are the **original** bankon.eth ENS
subname registrar work. They have been re-homed and substantially expanded in the agnostic
module at `openagents/bankoneth/contracts/` (see
`openagents/bankoneth/docs/DAIO_HANDOFF.md`).

They are **kept here, not deleted** — `daio/contracts/` is a separate Foundry project with its
own passing test suite (`v1/test/BankonSubnameRegistrar.t.sol`) and this tree remains the
historical reference. For all new work, edit the bankoneth copies.
